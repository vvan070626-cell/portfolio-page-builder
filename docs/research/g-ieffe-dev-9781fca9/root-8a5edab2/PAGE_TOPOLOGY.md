# Page Topology

1. Fixed header
   - Brand placeholder at left
   - Desktop navigation at right
   - Mobile menu and jump control below the desktop breakpoint
2. Hero
   - Oversized two-line title and monospaced positioning copy
   - Original black-and-white placeholder illustration
   - Asymmetric two-column desktop composition; stacked mobile composition
3. Practice overview
   - Three equal editorial columns on desktop
   - Numbered single-column blocks on mobile
4. Contact action
   - Large orange outlined pill control
   - Supporting replacement guidance
5. Footer
   - Identity placeholder and repeated short navigation

The page uses one normal document scroll container. The header is fixed; all other sections remain in document flow.
